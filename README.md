# 霧境學院｜暮鐘試煉

以原生 HTML、CSS、JavaScript 模組與 Canvas 製作的 2D 像素動作 Roguelite。版本包含 WASD 移動、滑鼠瞄準、雙技能施放、元素反應、敵潮與階段 Boss。

## 執行

在此資料夾執行 `node server.js`，再以瀏覽器開啟 `http://127.0.0.1:8000`。若已安裝 npm，也可執行 `npm start`。遊戲沒有外部遊戲框架或執行期套件依賴。

## 公開部署

GitHub Pages 設定及發布流程見 [DEPLOYMENT.md](DEPLOYMENT.md)。GitHub Actions 會先執行測試與 JavaScript 語法檢查，再發布遊戲入口、樣式與 `src/` 模組；本機 `node server.js` 開發流程不變。

## 操作

- `W`、`A`、`S`、`D`：八方向移動，斜向速度會正規化；移動會受障礙與世界邊界限制。
- 滑鼠：角色與法杖朝游標方向轉向；紅色準心及短距離虛線提示瞄準方向。滑鼠不控制移動。
- 左鍵：施放第一招式；右鍵：施放第二招式。兩欄冷卻及魔力分開計算；主畫面「魔法配置」可從四種魔法選兩種。
- 普攻自動鎖定射程內最近敵人，不消耗魔力。
- `Space` 朝游標方向閃避。
- 靠近庭園異象時按 `F` 互動：泉祠恢復生命／魔力；裂隙祭壇帶來短暫傷害增幅，但會召來敵潮。
- `Esc` 暫停／繼續；升級選擇亦可按 `1`、`2`、`3`
- 遊戲設定可開啟或關閉合成音效；瀏覽器會在首次操作後解鎖音效播放

滑鼠瞄準及施法座標會依照畫布縮放與攝影機偏移換算；視窗失焦會清除移動按鍵狀態。

## 局內成長

升級除通用能力外，可能依目前裝備的第一／第二招式提供專屬選擇：擴大焰爆彈、延長霜晶矢減速、增加鏈雷術目標，或擴大縛藤法陣。部分能力有疊加上限。

## 四種魔法

| 魔法 | 傷害 | 魔力 | 冷卻 | 戰術定位 |
|---|---:|---:|---:|---|
| 焰爆彈 | 31 | 14 | 0.9 秒 | 射程 500；命中點半徑 92 爆裂，周圍敵人受 66% 傷害。高傷害群體清場。 |
| 霜晶矢 | 17 | 8 | 0.52 秒 | 射程 460；命中周圍半徑 70 冰爆，附 38% 減速 1.25 秒。快速、低成本連射。 |
| 鏈雷術 | 18 | 12 | 0.78 秒 | 射程 520；最多命中 5 個目標，升級後最多 7 個；跳距 190，後續傷害乘以 0.74。 |
| 縛藤法陣 | 每跳 8 | 20 | 1 秒 | 射程 360；在準心位置生成半徑 112、持續 3 秒的法陣，每 0.5 秒造成傷害並限制普通敵人最多 0.38 秒。 |

玩家初始魔力為 76／100，自然回復速度為每秒 10 點。技能消耗仍會依威力與持續／範圍效果不同；Boss 控制上限獨立維持。

技能按下即朝準心方向施放；準心前向範圍內的敵人會作為方向鎖定對象。空處也可施放投射魔法；自然法陣則依射程與障礙調整落點。

## 元素反應

- 火焰與冰霜在同一敵人身上交會時觸發「蒸氣爆發」，造成額外範圍傷害。
- 雷電擊中帶有自然標記的敵人時觸發「雷藤蔓延」，向附近最多三名敵人傳導。
- 冰霜擊中帶有自然標記的敵人時觸發「冰封荊棘」；普通敵人短暫定身，Boss 只受短暫減速。
- 敵人頭上的元素像素標記會隨時間淡出；反應名稱與額外傷害以短暫 Canvas 提示顯示。

## 檔案

- `src/main.js`：Canvas 初始化、事件與遊戲迴圈
- `src/game.js`：狀態、戰鬥、敵人、升級與結算
- `src/entities.js`：玩家、敵人、法術投射物與像素角色繪製
- `src/magic.js`：四種魔法資料與技能欄設定
- `src/events.js`：兩種限時庭園異象與效果資料
- `src/reactions.js`：元素標記時間、反應條件、傷害、冷卻及 Boss 控制上限
- `src/movement.js`：角度平滑轉向
- `src/targeting.js`：自動普攻／技能目標搜尋
- `src/world.js`：學院地圖、裝飾、碰撞與小地圖
- `src/ui.js`：主畫面、設定、HUD、升級與結算介面
- `src/constants.js`：地圖、調色盤、能力資料與遊戲參數
